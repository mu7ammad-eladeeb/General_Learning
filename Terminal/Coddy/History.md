# The Birth of Unix

## 1973

### **An operating system written in C**

Version 4 Unix, released in November 1973, had its kernel largely rewritten in C. Dennis Ritchie had created C at Bell Labs between 1972 and 1973. Writing Unix in a high-level language made it much easier to move to new computers.

* **Unix:** A multitasking, multi-user operating system created at Bell Labs that laid the foundation for modern operating systems.
* **C Language:** A systems programming language developed by Dennis Ritchie, designed for hardware control and high performance.
* **Kernel:** The core component of an operating system managing hardware resources and system communication.
* **Dennis Ritchie:** Computer scientist at Bell Labs who created C and co-created Unix.
* **Bell Labs:** The research laboratory where Unix and C were developed.
* **High-Level Language:** Programming language offering strong abstraction from hardware details, improving portability.
* **Portability:** The capability of software to be run on different hardware architectures with minimal modification.
