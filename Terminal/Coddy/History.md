# The Birth of Unix

## 1973

### **An operating system written in C**

Version 4 Unix, released in November 1973, had its kernel largely rewritten in C. Dennis Ritchie had created C at Bell Labs between 1972 and 1973. Writing Unix in a high-level language made it much easier to move to new computers.

* **Unix:** A multitasking, multi-user operating system created at Bell Labs that laid the foundation for modern operating systems.
* **C Language:** A systems programming language developed by Dennis Ritchie, designed for hardware control and high performance.
* **Kernel:** The core component of an operating system managing hardware resources and system communication.
* **Dennis Ritchie:** Computer scientist at Bell Labs who created C and co-created Unix.
* **Bell Labs:** The research laboratory where Unix and C were developed.
* **High-Level Language:** Programming language offering strong abstraction from hardware details, improving portability.
* **Portability:** The capability of software to be run on different hardware architectures with minimal modification.

## 1975

### **Unix Spreads to Universities**

A 1956 legal agreement kept AT&T out of businesses other than communications, so Bell Labs licensed Unix instead of selling it. For Version 6, released in 1975, schools paid 200 dollars and others paid 20,000 dollars. It was the most widely used version into the 1980s.

* **AT&T Consent Decree of 1956:** A federal antitrust settlement that restricted AT&T from commercializing non-telecommunications technology, forcing Bell Labs to license software like Unix at minimal cost rather than sell it as a commercial product.
* **Bell Labs:** The research arm of AT&T where Unix was developed and distributed under restrictive antitrust licensing rules.
* **Version 6 Unix (V6):** Released in 1975, this was the first version of Unix to be widely distributed outside Bell Labs, especially to academic institutions, spawning early computing culture.
* **Software Licensing:** A legal mechanism governing the use and redistribution of software, which in Unix's case created a sharp price gap between non-profit universities and commercial companies.
* **Academic Adoption:** The practice of universities adopting software like Unix V6 for teaching and research, which directly led to widespread student experimentation, bug fixes, and derivative systems like BSD.

## 1988

### **A standard called POSIX**

Many companies made their own Unix versions, so a common standard was needed. The first POSIX standard was released in 1988. Richard Stallman suggested the name POSIX to the IEEE instead of the older name IEEE-IX.

* **POSIX (Portable Operating System Interface):** A family of standards specified by the IEEE Computer Society for maintaining compatibility between operating systems, enabling software to run across different Unix-like platforms.
* **Unix Wars:** The period of intense competition in the 1980s and 1990s among computer vendors creating proprietary, incompatible Unix variants, which created the necessity for a unifying open standard.
* **Richard Stallman:** An American software freedom activist and programmer who founded the GNU Project and the Free Software Foundation (FSF), known for advocating user software freedom.
* **IEEE (Institute of Electrical and Electronics Engineers):** A professional association for electronics engineering and electrical engineering that develops international standards for computing, networking, and telecommunications.
* **IEEE-IX:** The original draft name proposed for the operating system interface standard before Richard Stallman suggested the more pronounceable acronym POSIX.
