# The Birth of Unix

## 1969

**The first three programs**

In August 1969, Ken Thompson wrote the first key parts of Unix on a PDP-7 at Bell Labs. They were an assembler, an editor called ed and a shell. The rest of the system grew around them.

- **Ken Thompson:** An American computer scientist who helped create the Unix operating system.
- **Unix:** An operating system originally developed at Bell Labs. It introduced ideas and tools that influenced many modern operating systems, including Linux and macOS.
- **PDP-7:** A small computer manufactured by Digital Equipment Corporation (DEC). Ken Thompson used it to develop the early version of Unix.
- **Bell Labs:** Short for Bell Telephone Laboratories, a research and development organization where Unix was created.
- **Assembler:** A program that translates assembly language, which uses short symbolic instructions, into machine code that a computer's processor can execute.
- **Editor (`ed`):** A text-editing program used to create and modify text. The Unix editor `ed` was a line-based editor, meaning users edited text by specifying individual lines or ranges of lines.
- **Shell:** A program that provides a command-line interface, allowing users to type commands to run programs and interact with the operating system.
- **Operating system:** The main software that manages a computer's hardware and resources and provides services for other programs.
- **System:** In this context, the collection of software components that together form an operating system.
- **Grew around them:** Means that additional parts of Unix were developed after these three foundational programs, gradually building a more complete operating system.

## 1973

### **An operating system written in C**

Version 4 Unix, released in November 1973, had its kernel largely rewritten in C. Dennis Ritchie had created C at Bell Labs between 1972 and 1973. Writing Unix in a high-level language made it much easier to move to new computers.

* **Unix:** A multitasking, multi-user operating system created at Bell Labs that laid the foundation for modern operating systems.
* **C Language:** A systems programming language developed by Dennis Ritchie, designed for hardware control and high performance.
* **Kernel:** The core component of an operating system managing hardware resources and system communication.
* **Dennis Ritchie:** Computer scientist at Bell Labs who created C and co-created Unix.
* **Bell Labs:** The research laboratory where Unix and C were developed.
* **High-Level Language:** Programming language offering strong abstraction from hardware details, improving portability.
* **Portability:** The capability of software to be run on different hardware architectures with minimal modification.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1975

### **Unix Spreads to Universities**

A 1956 legal agreement kept AT&T out of businesses other than communications, so Bell Labs licensed Unix instead of selling it. For Version 6, released in 1975, schools paid 200 dollars and others paid 20,000 dollars. It was the most widely used version into the 1980s.

* **AT&T Consent Decree of 1956:** A federal antitrust settlement that restricted AT&T from commercializing non-telecommunications technology, forcing Bell Labs to license software like Unix at minimal cost rather than sell it as a commercial product.
* **Bell Labs:** The research arm of AT&T where Unix was developed and distributed under restrictive antitrust licensing rules.
* **Version 6 Unix (V6):** Released in 1975, this was the first version of Unix to be widely distributed outside Bell Labs, especially to academic institutions, spawning early computing culture.
* **Software Licensing:** A legal mechanism governing the use and redistribution of software, which in Unix's case created a sharp price gap between non-profit universities and commercial companies.
* **Academic Adoption:** The practice of universities adopting software like Unix V6 for teaching and research, which directly led to widespread student experimentation, bug fixes, and derivative systems like BSD.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1988

### **A standard called POSIX**

Many companies made their own Unix versions, so a common standard was needed. The first POSIX standard was released in 1988. Richard Stallman suggested the name POSIX to the IEEE instead of the older name IEEE-IX.

* **POSIX (Portable Operating System Interface):** A family of standards specified by the IEEE Computer Society for maintaining compatibility between operating systems, enabling software to run across different Unix-like platforms.
* **Unix Wars:** The period of intense competition in the 1980s and 1990s among computer vendors creating proprietary, incompatible Unix variants, which created the necessity for a unifying open standard.
* **Richard Stallman:** An American software freedom activist and programmer who founded the GNU Project and the Free Software Foundation (FSF), known for advocating user software freedom.
* **IEEE (Institute of Electrical and Electronics Engineers):** A professional association for electronics engineering and electrical engineering that develops international standards for computing, networking, and telecommunications.
* **IEEE-IX:** The original draft name proposed for the operating system interface standard before Richard Stallman suggested the more pronounceable acronym POSIX.

# Linux and Free Software

## 1991

### **Just a hobby**

On August 25, 1991, 21-year-old Linus Torvalds posted to the comp.os.minix newsgroup. He wrote that he was making a free operating system, just a hobby that would not be big and professional like GNU. That hobby became the Linux kernel.

* **Linus Torvalds:** A Finnish-American software engineer who created the Linux kernel in 1991 and later created the Git version control system.
* **comp.os.minix:** An early Usenet newsgroup dedicated to discussions surrounding the MINIX operating system, where Linus Torvalds famously announced his new operating system project.
* **Linux Kernel:** The core monolithic operating system kernel originally written by Linus Torvalds, which manages hardware hardware resources and forms the foundation of Linux-based operating systems.
* **GNU Project:** A free software, mass-collaboration project launched by Richard Stallman in 1983 aiming to create a complete, Unix-compatible free software operating system.
* **MINIX:** A Unix-like operating system created by Andrew S. Tanenbaum for educational purposes, which served as the initial inspiration and development platform for Linux.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1993

### **Slackware on floppy disks**

Patrick Volkerding released Slackware 1.00 on July 17, 1993, as 24 floppy disk images. Slackware is the oldest Linux distribution that is still maintained. It was the base for the first versions of SUSE Linux.

* **Slackware:** Created by Patrick Volkerding in 1993, it is the oldest actively maintained Linux distribution, known for its commitment to Unix-like simplicity, stability, and minimal default modifications.
* **Patrick Volkerding:** An American software developer who founded and continues to maintain Slackware Linux, making him one of the longest-serving maintainers in open-source software history.
* **Linux Distribution (Distro):** An operating system made from a software collection based upon the Linux kernel, package management system, and auxiliary tools (such as Slackware, Debian, or Red Hat).
* **Floppy Disk Images:** Raw byte-for-byte binary files containing the contents and structure of physical 3.5-inch magnetic storage disks, used in the early 1990s as the primary installation medium before CDs became standard.
* **SUSE Linux:** A major commercial European Linux distribution originating in Germany, whose earliest releases (SLS/S.u.S.E. Linux) were directly derived from translated and customized versions of Slackware.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1998

### **The term open source**

The term open source was launched as a campaign in 1998 by a group that included Christine Peterson and Eric Raymond. In February 1998, Bruce Perens and Eric Raymond founded the Open Source Initiative to promote it.

* **Open Source:** A software development model and philosophy where source code is made freely available to the public for viewing, modification, enhancement, and redistribution.
* **Open Source Initiative (OSI):** A non-profit public benefit organization founded in 1998 by Bruce Perens and Eric Raymond to educate about and advocate for the use of open-source software and manage the Open Source Definition.
* **Christine Peterson:** A foresight specialist and co-founder of the Foresight Institute who coined the phrase "open source" in February 1998 to replace the confusing term "free software."
* **Eric S. Raymond:** An American software developer and author of *The Cathedral and the Bazaar*, an influential essay analyzing open-source software development methods.
* **Bruce Perens:** An American computer programmer and open-source advocate who co-founded the Open Source Initiative and authored the Open Source Definition based on the Debian Free Software Guidelines.

# Commands With a Story

## 1973

### **What grep stands for**

The name grep comes from the ed editor command g/re/p, meaning global, regular expression, print. That command printed every line that matched a pattern. grep became its own program and was first included in Version 4 Unix.

* **grep:** A command-line utility in Unix and Unix-like operating systems that searches plain-text data sets for lines matching a regular expression.
* **`ed`:** The original standard text editor for the Unix operating system, designed by Ken Thompson, which operated line-by-line using commands like `g/re/p`.
* **`g/re/p`:** The specific `ed` sequence representing **g**lobal / **r**egular **e**xpression / **p**rint, which instructs the editor to search globally through a file for matches to a regular expression and print those lines.
* **Regular Expression (regex):** A sequence of characters that specifies a match pattern in text, widely used in string-searching algorithms and text processing.
* **Version 4 Unix:** The November 1973 release of Unix that marked its transition to being rewritten in C, which was also the first official release to include `grep` as a standalone binary tool.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1976

### **Why vi moves with h, j, k and l**

Bill Joy used a Lear Siegler ADM-3A terminal, which had no separate arrow keys. Instead, arrows were printed on the H, J, K and L keys. vi used those keys to move the cursor, and Vim still does.

* **Bill Joy:** An American computer scientist and co-founder of Sun Microsystems who created the `vi` text editor and the C shell (`csh`), and played a key role in developing BSD Unix.
* **Lear Siegler ADM-3A:** An iconic computer terminal manufactured in the 1970s that featured a minimalist keyboard layout where cursor directional arrows shared physical keys with H, J, K, and L.
* **vi:** A visual mode text editor developed by Bill Joy in 1976 for early BSD Unix systems, famous for its modal editing paradigm and keyboard-centric navigation.
* **Vim (Vi IMproved):** A highly configurable, open-source clone of `vi` created by Bram Moolenaar in 1991 that retains original `vi` keybindings like `hjkl` navigation while adding modern editing features.
* **Modal Editing:** A user interface concept where keys perform different functions depending on the active mode (e.g., Command Mode vs. Insert Mode), allowing efficient document editing without a mouse.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1979

### **Why tar is named after tape**

The tar command came to Unix in January 1979. Its name is short for tape archive, because it was made for storing files on magnetic tape. Today people mostly use it to bundle files into one archive.

* **`tar` (Tape Archive):** A computer software utility in Unix and Unix-like systems used to combine multiple files and directories into a single composite archive file.
* **Magnetic Tape Storage:** A sequential access physical storage medium consisting of a thin, magnetizable coating on a long strip of plastic film, heavily utilized in early computing for data backups.
* **Tarball:** A common colloquial term for a single archive file produced by the `tar` command, often compressed using secondary tools like `gzip` (`.tar.gz`) or `bzip2` (`.tar.bz2`).
* **Archive File:** A single file containing one or more sub-files alongside associated metadata (such as permissions, timestamps, and directory structure), created to simplify storage and transfer.
* **Sequential Access:** A data storage access method where data is read or written in a continuous linear sequence, characteristic of magnetic tape drives and the linear design of `tar`.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1980

### **Where sudo was born**

Robert Coggeshall and Cliff Spencer wrote the first version of sudo around 1980 at the computer science department of SUNY Buffalo. The name originally meant superuser do. It lets a normal user run one command with administrator rights.

* **sudo:** A command-line program for Unix and Unix-like operating systems that allows permitted users to execute commands with elevated privileges (typically as the superuser or root account).
* **Superuser (root):** The administrative user account in Unix-like operating systems with unrestricted permissions and access to all system resources and files.
* **SUNY Buffalo (University at Buffalo):** A major public research university in New York where developers Robert Coggeshall and Cliff Spencer created the initial `sudo` tool to manage system access.
* **Robert Coggeshall & Cliff Spencer:** Computer science staff members at SUNY Buffalo who authored the original `sudo` program around 1980 to eliminate the need to share the root account password.
* **Principle of Least Privilege:** A fundamental computer security concept where users are given only the minimum level of access needed to perform a specific task, which `sudo` enforces by granting temporary root privileges for individual commands.

# Teletypes and Terminals

## 1963

### **Ctrl+D means you are done**

Ctrl+D sends the ASCII End of Transmission character. In a Unix terminal it signals the end of input, so a program waiting for text knows you are finished. Pressing it at an empty shell prompt usually closes the shell.

* **ASCII (American Standard Code for Information Interchange):** A character encoding standard designed in 1963 for electronic communication, mapping text characters and control codes to digital values.
* **End of Transmission (EOT):** A non-printable ASCII control character (value 4) originally used in telecommunications to signal the end of a transmission, mapped to `Ctrl+D` in Unix-like terminal environments.
* **Terminal (TTY):** An input/output environment that allows users to interact with an operating system kernel using text-based commands and control sequences.
* **EOF (End-of-File):** A condition in computer operating systems where no more data can be read from a data source, signaled in interactive shell sessions via the `Ctrl+D` shortcut.
* **Unix Shell:** A command-line interpreter (such as `bash` or `zsh`) that executes commands typed by the user, which interprets an EOF signal on an empty prompt as a command to exit the session.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1964

### **Who named the shell?**

In 1964, Louis Pouzin had the idea of using commands somehow like a programming language. He called the program that does this a shell, and he described it for the Multics system. Every command-line interpreter since has been called a shell.

* **Louis Pouzin:** A French computer scientist who invented the concept of the command-line shell for Multics and developed the datagram packet-switching network architecture (CYCLADES) that laid the foundation for the Internet.
* **Multics (Multiplexed Information and Computing Service):** An influential early time-sharing operating system started in 1964 by MIT, GE, and Bell Labs that pioneered many fundamental computer system concepts, including file system hierarchies and the shell.
* **Shell:** A user interface program that acts as an outer layer surrounding the operating system kernel, interpreting user commands and scripting logic to execute system operations.
* **Command-Line Interpreter (CLI):** A computer program that reads and executes text-based commands entered by a user, converting high-level user instructions into system execution calls.
* **Time-Sharing Systems:** An operating system architecture that allows multiple users to access a single central computer simultaneously through independent terminals, creating the need for user command interpreters like shells.

**Source:** en.wikipedia.org (Added details by Gemini AI)

## 1978

**The VT100 video terminal**

DEC introduced the VT100 video terminal in August 1978. It was one of the first terminals to support ANSI escape codes, special sequences that move the cursor and change how text looks. Terminal programs today still understand those codes.

- **DEC:** Stands for *Digital Equipment Corporation*, a computer company that developed computers and terminals, including the VT100.
- **VT100:** A video terminal introduced by DEC in 1978. It allowed users to interact with a computer by typing commands and viewing text on a screen.
- **Video terminal:** An electronic device consisting of a screen and a keyboard that lets a person communicate with a computer.
- **ANSI:** Stands for *American National Standards Institute*, an organization that coordinates standards used in different industries.
- **ANSI escape codes:** Special character sequences that control how text appears in a terminal. They can move the cursor, change text colors, clear parts of the screen, and perform other formatting actions.
- **Escape code:** A sequence of characters that tells a terminal to perform a special action instead of displaying ordinary text.
- **Cursor:** The visible indicator showing where the next character will appear on the screen.
- **Terminal:** An interface that lets users interact with a computer by entering commands and viewing text output.
- **Terminal program:** Software that provides a text-based interface for interacting with a computer or running commands.
- **Support:** In computing, to recognize and correctly handle a feature or technology.

**Source:** en.wikipedia.org (Added details by ChatGPT)

## 1984

### **The terminal becomes a window**

In the summer of 1984, Mark Vandevoorde, a student of Jim Gettys, wrote xterm. It became the standard terminal of the X Window System. A terminal emulator like xterm is a program that pretends to be a hardware terminal inside a window.

* **`xterm`:** The standard terminal emulator for the X Window System, originally developed by Mark Vandevoorde to allow graphical displays to run command-line interface sessions.
* **Terminal Emulator:** A software application that replicates the functionality of a physical video terminal or teletype hardware inside a graphical user interface (GUI) window.
* **X Window System (X11):** A graphical windowing system developed at MIT in 1984 that provides the core framework and network protocol for building graphical user interfaces on Unix and Unix-like operating systems.
* **Jim Gettys:** A computer scientist and prominent contributor to the X Window System who mentored Mark Vandevoorde during the creation of `xterm` at MIT.
* **Hardware Terminal:** A physical hardware device consisting of a display screen and keyboard (such as the VT100) used to send data to and display data from a remote mainframe or central computer.
